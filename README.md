# Soya-Been-Disease-Detection

## Overview
Soya-Been-Disease-Detection is an Android application designed to identify various diseases in soybean plants using image classification. The app utilizes TensorFlow Lite for on-device machine learning to classify images of soybean leaves and provide disease predictions.

## Features
- **Image Classification**: Classifies images of soybean leaves to detect diseases.
- **Camera and Gallery Support**: Users can capture images using the device's camera or select existing images from the gallery.
- **Real-time Predictions**: Provides instant disease predictions with confidence levels.
- **User-friendly Interface**: Simple and intuitive UI for easy navigation and usage.

## Technical Details
- **Language**: Java
- **Framework**: Android
- **Machine Learning**: TensorFlow Lite
- **Minimum SDK**: 24
- **Target SDK**: 35

## Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project in Android Studio.
3. Build and run the application on an Android device or emulator.

## Usage
1. Launch the app on your Android device.
2. Use the camera to capture an image of a soybean leaf or select an image from your gallery.
3. View the predicted disease and confidence level.

## Labels
The app can detect the following diseases:
- Healthy
- Frogeye Leaf Spot
- Target Leaf Spot
- Yellow Mosaic
- Sudden Death Syndrome
- Bacterial Pustule
- Rust
